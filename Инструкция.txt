# 🤖 Telegram AutoReply

## Инструкция по установке и использованию

Telegram AutoReply — персональный автоответчик для Telegram, который автоматически отвечает на входящие личные сообщения заранее заданным текстом.

Программа работает на вашем компьютере и использует ваш собственный Telegram API ID и API Hash.

---

# 📋 1. Что необходимо

Перед установкой убедитесь, что у вас есть:

* Windows 10 или Windows 11
* Telegram-аккаунт
* подключение к интернету
* Python 3.10 или новее
* Telegram API ID
* Telegram API Hash

---

# 🐍 2. Установка Python

Если Python ещё не установлен:

1. Откройте официальный сайт Python:
   https://www.python.org/downloads/

2. Скачайте актуальную версию Python 3.

3. Запустите установщик.

4. **ВАЖНО:** перед установкой поставьте галочку:

`Add Python to PATH`

5. Нажмите `Install Now`.

После установки можно проверить Python:

1. Нажмите `Win + R`.
2. Введите `cmd`.
3. Нажмите Enter.
4. Выполните:

```text
python --version
```

Если команда не сработала, попробуйте:

```text
py --version
```

Если отображается версия Python, установка выполнена успешно.

---

# 🔑 3. Получение Telegram API ID и API Hash

Для работы программы необходимо создать собственные Telegram API данные.

1. Откройте:

https://my.telegram.org/apps

2. Авторизуйтесь через свой Telegram-аккаунт.

3. Откройте раздел **API development tools**.

4. Создайте приложение.

5. Telegram покажет:

* `api_id`
* `api_hash`

Сохраните эти данные.

**Никому не отправляйте свой API Hash.**

Программа не требует передачи продавцу:

* пароля Telegram;
* SMS-кода;
* кода авторизации;
* QR-кода;
* файла Telegram-сессии.

---

# ⚙️ 5. Настройка API

В папке программы найдите файл:

```text
.env.example
```

Сделайте его копию и переименуйте копию в:

```text
.env
```

Откройте `.env` через Блокнот.

Внутри будет:

```text
TG_API_ID=12345678
TG_API_HASH=your_api_hash_here
```

Замените значения на свои данные:

```text
TG_API_ID=123456789
TG_API_HASH=ваш_api_hash
```

Сохраните файл.

**Не публикуйте `.env` в интернете.**

---

# ⚙️ 6. Настройка автоответчика

Основные настройки находятся в:

```text
config.json
```

Откройте файл через Блокнот.

## Текст автоответа

Найдите:

```json
"auto_reply": "Привет! Я сейчас занят и отвечу позже."
```

И замените текст на свой.

Например:

```json
"auto_reply": "Привет! Сейчас играю и не могу ответить. Напишу позже."
```

---

# 🔘 7. Включение и отключение автоответчика

В `config.json` есть параметр:

```json
"enabled": true
```

`true` — автоответчик включён.

```json
"enabled": false
```

`false` — автоответчик выключен.

---

# ⏱️ 8. Интервал между ответами

Параметр:

```json
"reply_once_minutes": 30
```

означает, что одному пользователю программа не будет отправлять новый автоответ чаще одного раза за указанное количество минут.

Например:

```json
"reply_once_minutes": 60
```

Один пользователь получит максимум один автоматический ответ в течение часа.

---

# 👤 9. Игнорирование пользователей

Можно указать пользователей, которым автоответчик не должен отвечать.

Пример:

```json
"ignore_users": [
    "username",
    "123456789"
]
```

Можно использовать как username, так и Telegram ID.

---

# 👥 10. Белый список

Можно сделать так, чтобы автоответчик отвечал только определённым пользователям.

Например:

```json
"only_users": [
    "username1",
    "username2"
]
```

Если список пустой:

```json
"only_users": []
```

автоответчик работает для всех подходящих личных сообщений.

---

# 🔎 11. Ответ по ключевым словам

Можно настроить автоответ только на сообщения, содержащие определённые слова или фразы.

Например:

```json
"keywords": [
    "привет",
    "ты где",
    "играешь"
]
```

Теперь автоответчик будет реагировать только на сообщения, содержащие одно из этих слов или выражений.

Если нужно реагировать на все сообщения, оставьте:

```json
"keywords": []
```

---

# 🎯 12. Точное совпадение ключевого слова

По умолчанию используется режим:

```json
"keyword_mode": "contains"
```

Например, ключевое слово:

```text
привет
```

может сработать на:

```text
привет
привет, ты где?
ну привет
```

Для точного совпадения можно использовать:

```json
"keyword_mode": "exact"
```

---

# 🚀 13. Первый запуск

После настройки `.env` и `config.json`:

1. Запустите:

```text
install.bat
```

2. Дождитесь окончания установки.

3. После этого запустите:

```text
start.bat
```

4. При первом запуске программа попросит авторизоваться в Telegram.

Введите:

* номер телефона;
* код Telegram;
* пароль двухэтапной аутентификации, если он установлен.

После успешной авторизации программа подключится к аккаунту.

---

# ✅ 14. Как понять, что всё работает

После успешного запуска в окне появится информация примерно такого вида:

```text
Telegram AutoReply
Статус автоответа: ВКЛ
Подключение к Telegram...

[+] Авторизован: @username
[+] AutoReply запущен.
[+] Для остановки нажми Ctrl+C.
```

После этого программа работает в фоне.

Когда вам приходит подходящее личное сообщение, автоответчик отправляет установленный текст.

# 🔐 16. Безопасность

Программа использует собственные API-данные пользователя.

**Никогда не передавайте другим людям:**

* Telegram-пароль;
* код подтверждения;
* пароль 2FA;
* `.env`;
* файл Telegram-сессии.

После первого входа программа создаёт локальный файл сессии.

Этот файл содержит данные авторизации и должен храниться в безопасности.

Если вы переносите программу на другой компьютер, может потребоваться повторная авторизация.

---

# ⚠️ 17. Важная информация

Программа предназначена для автоматизации ответов на входящие сообщения на собственном Telegram-аккаунте.

Не используйте её для:

* массовой рассылки;
* спама;
* мошенничества;
* обхода ограничений Telegram;
* автоматизированных действий, нарушающих правила Telegram.

Пользователь самостоятельно отвечает за использование программы и соблюдение правил Telegram.

---

# ❓ 18. Если программа не запускается

### Python не найден

Установите Python и убедитесь, что при установке была включена:

```text
Add Python to PATH
```

После этого перезапустите компьютер или командную строку.

### Ошибка API ID / API Hash

Проверьте `.env`.

Должно быть:

```text
TG_API_ID=ваш_api_id
TG_API_HASH=ваш_api_hash
```

Без кавычек.

### Не приходит автоответ

Проверьте:

1. `"enabled": true`
2. правильность текста в `config.json`;
3. не находится ли пользователь в `ignore_users`;
4. не установлен ли `only_users`;
5. не установлены ли ключевые слова, которым сообщение не соответствует;
6. не действует ли cooldown.

### Нужно изменить настройки

Измените `config.json` и перезапустите программу.
